ASSIST v0.2.0 — 原型集成 + 真实 PowerShell / Bash

1. 完整解压。关闭旧版 assist / assist-server。
2. Windows 双击 start-demo.cmd。不要把管理页链接发给客户。
3. 管理页创建请求 → 打开客户页 → 下载并打开新版 assist（第一次）。
4. 旧 ping 版需重新下载一次，更新到 v0.2.0。
5. 设备连接后，回管理页点击右下角 ? → 预览与命令 → 提交并自动判定。
6. 白名单命令自动执行；黑名单或未收录命令直接阻断，无需客户逐条审批。
7. 页面显示策略判定与真实输出。结束后查看撤销和停止回执。

只看原型：双击 index.html。file:// 为模拟模式，不运行命令。
真实功能：必须从 assist-server 打开的 HTTP 页面访问。

本版本未签名，非只读沙箱，仅用于有授权的测试设备。
这是逐条非交互式命令执行；不是保持状态的 PTY 终端。
Windows 版真实运行与浏览器唤起仍需现场测试。
详见 README.md、TEST-REPORT.md。
